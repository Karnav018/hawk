3 ENTERPRISE — FLAT SURFACES

Enterprise pass over the same screens: the emission wash, blur, glass alpha, gradient buttons, drop shadows and orb motion are gone. Every surface is now an opaque fill on a solid hairline, at the same value it read at before — layout, copy and spacing are untouched. Accent stays #5b8cff on dark so citations and progress hold. Type has three jobs and keeps to them: Instrument Serif set large for every question and headline (second line italic), Archivo for interface copy and for labels as tracked caps, Martian Mono reserved strictly for numerals — scores, timers, dates, percentages. Spacing is one 4px scale: 24 between blocks, 16 inside panels, 64px rows. Home is the voice screen (2c) — no separate ask screen. Screens run in flow order: sign-in → email → verify → profile → connect → permissions → scope → indexing → ready → home → answer → capture → library → plans → subscription. Tap the orb on 2c four times to reach its fifth state, the free-tier limit that leads into 3n.

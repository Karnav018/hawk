3 DARK THEME — DEFAULT

Default theme. Near-black navy, your emission texture as a low ambient wash on every screen, glass panels on hairlines, accent lifted to #5b8cff so citations and progress hold on dark. Type has three jobs and keeps to them: Instrument Serif set large for every question and headline (second line italic), Archivo for interface copy and for labels as tracked caps, Martian Mono reserved strictly for numerals — scores, timers, dates, percentages. Spacing is one 4px scale: 24 between blocks, 16 inside panels, 64px rows. Home is the voice screen (2c) — no separate ask screen.
